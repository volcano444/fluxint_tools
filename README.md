FLUXXINT Tools

Toolkit berbasis Python dengan antarmuka CLI untuk menjalankan berbagai utilitas melalui satu terminal.

Requirements

- Python 3.10+
- Git
- pip

Installation (Termux)

1. Update package

pkg update && pkg upgrade -y

2. Install dependencies

pkg install python git -y

3. Clone repository

git clone https://github.com/volcano444/fluxint_tools.git

4. Masuk ke folder

cd fluxx-api

5. Install library

pip install -r requirements.txt

6. Jalankan aplikasi

python main.py

Update

Untuk memperbarui aplikasi:

git pull origin main
pip install -r requirements.txt

Notes

- Gunakan Python versi yang kompatibel.
- Pastikan koneksi internet tersedia.
- Gunakan Tools Dengan bijak
